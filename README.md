# 논문 번역기 (PaperTranslator)

영어 논문·슬라이드 PDF를 한글 PDF로 바꿔주는 프로그램입니다.
원본 레이아웃(수식·표·그림 위치)은 그대로 두고 본문만 번역합니다.

## 사용법

1. `llama.cpp` 서버를 켭니다 (`http://localhost:8080`)
2. `PaperTranslator.exe`를 더블클릭합니다 → 브라우저가 자동으로 열립니다
3. PDF 파일을 선택합니다 (여러 개 한 번에 가능)
4. 필요하면 모델·언어를 바꾸고 **한글화 시작**을 누릅니다
5. 끝나면 `비교하기`로 원문과 결과를 좌우로 대조할 수 있습니다

## 참고

- 상단 `모델 상태`가 "연결 안 됨"이면 llama.cpp 서버를 먼저 켜세요.
  상용 API(OpenAI·Claude·Gemini)를 쓰려면 모델 선택 후 API 키를 입력하세요 (키는 저장되지 않음).
- 번역 결과는 `outputs/` 폴더에 저장됩니다.
- 논문이 길면(20~30페이지) 수십 분 걸릴 수 있습니다. 페이지 지정(예: `0-1`)으로 나눠서 돌리세요.
- 종료는 작업관리자에서 `PaperTranslator.exe`를 끝내세요 (브라우저를 닫아도 프로그램은 계속 돕니다).

## 폴더 설명

- `PaperTranslator.exe` — 본 프로그램 (더블클릭)
- `test/` — 테스트용 영어 논문
- `reference/` — 번역 규칙 기준 (번역 전/후 예시)
- `outputs/` — 번역된 PDF 저장 위치
- `src/` — 프로그램 원본 코드 (수정·재빌드용)
